# Argos widget demo

A production-style storefront that embeds the real [Argos](https://app.try-argos.ai) live chat widget. The host site is deliberately framework-free; Vite only handles the build and environment variables.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Set `VITE_ARGOS_WIDGET_ID` to an active widget ID from **Argos → Settings → Live Chat → Installation**.

For a one-off preview without editing environment variables, pass the ID in the URL:

```text
http://localhost:5173/?widgetId=YOUR_WIDGET_ID
```

The query parameter is only a public widget identifier—the same value exposed in the installation snippet. It is not a credential.

## Deploy to Vercel

1. Import this repository in Vercel.
2. Keep the detected **Vite** framework preset.
3. Add `VITE_ARGOS_WIDGET_ID` in the Vercel project environment variables.
4. Deploy.

`VITE_ARGOS_WIDGET_ORIGIN` defaults to `https://widget.try-argos.ai`; set it only when testing a different Argos environment.

If the widget has a non-empty **Embed domains** list, add the final Vercel origin (for example `https://your-project.vercel.app`) in Argos. An empty list allows embedding on any domain.

## Integration

The demo dynamically adds the same one-line loader generated by the Argos installation screen:

```html
<script
  src="https://widget.try-argos.ai/widget.js"
  async
  data-widget-id="YOUR_WIDGET_ID"
></script>
```

The loader owns the launcher and injects a sandboxed iframe. No Argos application code or CSS is copied into the host page.
