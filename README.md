# Argos widget demo

A production-style storefront and playground for the real [Argos](https://app.try-argos.ai)
live chat widget. Paste any active widget ID into the control bar to test its production embed.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

The playground starts with widget `01KY0HXPSVMD7HR2RQ5C4RHAP2`. Enter another ID in the
form to reload the page with that widget. The selected ID is stored in the shareable
`?widgetId=…` URL parameter.

## Deploy to Vercel

1. Import this repository in Vercel.
2. Keep the detected **Vite** framework preset.
3. Deploy. No environment variables are required.

If the widget has a non-empty **Embed domains** list, add the final Vercel origin (for example `https://your-project.vercel.app`) in Argos. An empty list allows embedding on any domain.

## Integration

The playground dynamically adds the same loader generated by the Argos installation screen:

```html
<script
  src="https://widget.try-argos.ai/widget.js"
  async
  data-widget-id="SELECTED_WIDGET_ID"
></script>
```

The loader owns the launcher and injects a sandboxed iframe. No Argos application code or CSS is copied into the host page.
